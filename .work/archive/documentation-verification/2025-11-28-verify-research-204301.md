## Patterns Observed

1. **Configuration System Confusion**: Reviewers confused `plugin/hooks.json` (Claude Code plugin registration) with `plugin/hooks/gates.json` (Turboshovel gate configuration). These serve different purposes.

2. **Path Confusion**: Plugin context directory exists at `plugin/context/` not `plugin/hooks/context/`. Code is correct, review checked wrong location.

3. **Documentation Bugs Confirmed**: Multiple documentation issues verified (enabled_commands, examples path, SubagentStop scoping not documented).

4. **Validation vs Registration**: KNOWN_HOOK_EVENTS (12) validates hook types; plugin/hooks.json (11) registers hooks for CLI; gates.json (3) configures quality gates. Three different counts for three different purposes.

5. **Test-Implementation Gap**: Plugin gate tests may not match implementation behavior (throw vs return blockReason for circular references).
