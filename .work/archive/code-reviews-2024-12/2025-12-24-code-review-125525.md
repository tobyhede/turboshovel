### NON-BLOCKING Issues

#### 1. Incomplete Terminology Update (Task 1)

**Severity:** Minor
**Location:** `plugin/hooks/hooks-app/src/cli/workflow-cli.ts`

**Issue:**
The terminology fix from "step" to "Task" is incomplete. Two instances remain:

1. **Line 128** - Command description:
   ```typescript
   .description('Advance to the next step or mark task complete')
   ```
   Should be: `'Advance to the next Task or mark task complete'`

2. **Line 129** - Option help text:
   ```typescript
   .option('--step <n>', 'Jump to specific step (for GOTO)')
   ```
   Should be: `'Jump to specific Task (for GOTO)'`

**Note:** The option name `--step` should remain unchanged for backward compatibility (CLI flags are part of the public API), but the help text should be updated.

**Recommendation:**
Update the help text strings to use "Task" terminology consistently. This can be addressed in a follow-up commit.
