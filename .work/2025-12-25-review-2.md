**Magic constant "first prompt" assumption:**
- Description: `getTaskPrompt` always returns `task.prompts[0].text` without documentation of why the first prompt is chosen. If tasks can have multiple prompts, this decision should be explicit and documented, or a selector parameter should be added.
- Location: plugin/core/src/workflow/hooks/substitute.ts:32
- Action: Add JSDoc comment explaining "Returns the first prompt when multiple exist, as task prompts are ordered by precedence" OR consider adding optional `promptIndex` parameter if multiple prompts need different selection logic in the future.

**Error swallowing in loadAndSubstitutePrompt:**
- Description: The `catch` block in `loadAndSubstitutePrompt` silently catches all errors without logging or distinguishing between "file not found" (expected) vs "parse error" (unexpected). This makes debugging harder.
- Location: plugin/core/src/workflow/hooks/subagent-start.ts:99
- Action: Consider logging parse errors at debug level: `catch (error) { if (!(error instanceof Error && error.message.includes('ENOENT'))) { console.debug('Failed to load workflow prompt:', error); } return undefined; }`. This maintains graceful degradation while improving debuggability.

**Test organization inconsistency:**
- Description: The new test suite "handleSubagentStart with prompt injection" is a separate describe block rather than being nested under the main "handleSubagentStart" describe. This creates parallel top-level suites for the same function.
- Location: plugin/core/__tests__/workflow/hooks/subagent-start.test.ts:107
- Action: Consider nesting as `describe('handleSubagentStart', () => { describe('with prompt injection', () => { ... }) })` to maintain clear test hierarchy and make it easier to understand that all tests relate to the same function.

**formatAgentContext string building pattern:**
- Description: The function builds markdown output using array of strings + join, but mixes push operations with initial array literal and conditional logic. While functional, the pattern could be more consistent.
- Location: plugin/core/src/workflow/hooks/subagent-start.ts:105-125
- Action: Consider extracting prompt section as separate helper or using template literals for better readability:
```typescript
const promptSection = prompt ? `\n## Task Prompt\n\n${prompt}\n` : '';
return `## Workflow Agent Context\n\nAGENT_ID: ${agentId}\nTASK_ID: ${taskIdToString(taskId)}\n${promptSection}\n## Commands\n\n...`;
```

**Subtask test data change in existing test:**
- Description: The existing test was modified to change subtask from 'A' to '1', which suggests the test data format changed but without explanation in commit message or comments.
- Location: plugin/core/__tests__/workflow/hooks/subagent-start.test.ts:28,39
