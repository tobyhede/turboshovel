- Description: The `session.properties.test.ts` file contains a flaky test caused by `fc.date()` arbitrary generating invalid dates. - Location: `/Users/tobyhede/psrc/turboshovel/plugin/hooks/hooks-app/__tests__/session.properties.test.ts:15`
- Action: The `fc.date()` arbitrary can generate invalid dates that fail `toISOString()`. Filter to valid dates only:
  ```typescript
  started_at: fc.date({ min: new Date('2000-01-01'), max: new Date('2100-01-01') })
    .filter(d => !isNaN(d.getTime()))
    .map(d => d.toISOString()),
  ```
  Alternatively, use `fc.integer()` within a valid range and construct dates manually. Run `npm test` multiple times to verify stability.
